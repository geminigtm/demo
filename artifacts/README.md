# Demo Artifacts

Store non-code outputs referenced in the walkthrough (text, CSV, PDF). Keep everything synthetic.

What to include:
- Email drafts as `.txt` (one per lead) or a small `.md` bundle.
- Compatibility/score tables as `.csv` with fake entities only.
- Graph exports (PNG/PDF) created from the mock data.

What to avoid:
- No source code, configs, or API payloads from production.
- No personally identifiable information or real company references.

Tip: Match filenames to the screens they support (e.g., `08-outreach-drafts.txt`, `07-graph.png`).
